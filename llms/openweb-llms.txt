# OpenWeb Documentation

> OpenWebOS brings power back to publishers. It’s your unified, end-to-end suite for building a community, harnessing first-party data, achieving sustainable revenue, and future-proofing your businesses. It’s your OS to win on the web.

## API Reference
- [Request an OpenWeb API token](https://developers.openweb.com/reference/post_v1-publisher-auth.md): Generates a JWT token to be used for OpenWeb API
- [Request export](https://developers.openweb.com/reference/post_v4-export.md): Initiates an export of comments, users, and ranks by Conversation ID or date range.
- [Check export status](https://developers.openweb.com/reference/get_v4-export-status.md): Retrieves the status of the export
- [List finished exports](https://developers.openweb.com/reference/get_v4-export-list.md): Lists finished exports
- [Abort export](https://developers.openweb.com/reference/get_v4-export-abort.md): Cancels the export
- [Request export](https://developers.openweb.com/reference/post_v2-export-comments.md)
- [Check export status](https://developers.openweb.com/reference/get_v2-export-comments-status.md): Retrieves the status of the export
- [List finished exports](https://developers.openweb.com/reference/get_v2-export-comments-list.md): Lists finished exports
- [Abort export](https://developers.openweb.com/reference/get_v2-export-comments-abort.md): Cancels the export
- [List top comments within an entire spot](https://developers.openweb.com/reference/get_top-comments-spot.md): Retrieve the top comments for a Spot ID in a given time period
- [List top comments for an individual user](https://developers.openweb.com/reference/get_top-comments-user.md): Retrieve the top user comments in a given time period
- [List top comments within a specific Conversation](https://developers.openweb.com/reference/get_top-comments-conversation.md): Retrieve the top Conversation comments from all time
- [List trending articles for a spot](https://developers.openweb.com/reference/get_trending-articles.md): Retrieve the trending article for a Spot ID in a given time period
- [Register a new user](https://developers.openweb.com/reference/post_sso-v1-user.md): Registers a new user
- [Retrieve user details](https://developers.openweb.com/reference/get_sso-v1-user-primary-key.md): Retrieves user details
- [Delete user](https://developers.openweb.com/reference/delete_sso-v1-user-primary-key.md): Deletes the OpenWeb user data of an existing SSO user  When requested by a user, you must delete the user’s OpenWeb account to remain GDPR compliant. Once the user has been deleted, comments by the deleted user remain and are linked to a random guest user.
- [Configure additional user settings](https://developers.openweb.com/reference/get_sso-v1-register-user.md): Adds more information to the user, such as bio, notification settings, and email
- [Update user details](https://developers.openweb.com/reference/get_sso-v1-update-user.md): Updates the OpenWeb user data of an existing SSO user
- [Create article SEO markup](https://developers.openweb.com/reference/post-article.md): Returns the SEO markup used by Google and other search engines to index your pages
- [Create comment SEO markup](https://developers.openweb.com/reference/post-comment.md): Returns the SEO markup used by Google and other search engines to index your comments
- [Create Live Blog SEO markup](https://developers.openweb.com/reference/post-liveblog.md): Returns the SEO markup used by Google and other search engines to index your comments
- [Create score and reviews SEO markup](https://developers.openweb.com/reference/post-reviews.md): Returns aggregate score and the individual reviews
- [Get moderation policy by article ID](https://developers.openweb.com/reference/get-conversation-policy-spot-spot_id-post-post_id.md): Retrieves the moderation policy for a specific article
- [Set moderation policy by article ID](https://developers.openweb.com/reference/post-conversation-policy-spot-spot_id-post-post_id-policy.md): Defines the moderation policy for an article
